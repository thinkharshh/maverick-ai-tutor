Tech architecture

The full Confluent journey — voice session to the next drill, in seconds.

Every preventive-maintenance drill on the floor becomes a stream event, gets enriched by Claude inside Flink, lands in Iceberg for the IATF 16949 / ISO 9001 audit trail, and triggers a freshly tailored follow-up scenario — all on Confluent Cloud, while the technician is still walking back the last procedure.

  1. Technician + Aarya on the line

    WaterrAI hosts a Daily.co WebRTC room with Aarya, the senior PM coach persona. She drills one station (LOTO, hydraulic press, paint booth…) and scores three goals at session end.

    persona · scenario · goals
  2. Webhook → Kafka producer

    An HMAC-verified webhook in server.js converts session.analysis_complete into a LearningEvent envelope and produces to Kafka via KafkaJS over TLS+SASL.

    POST /webhook/waterr
  3. learning.events topic

    Partitioned by learner.id for per-technician ordering. Avro-validated against a Schema Registry contract — forward / backward compatible across plant rollouts.

    key = learner.id · 7d retention
  4. Flink SQL + ML_PREDICT

    A single watermarked SQL job reads each event, scores difficulty from average_score, and calls Claude inside the stream via Confluent AI Model Inference to author the next coach prompt. No separate AI service.

    ML_PREDICT('next_lesson_model', …)
  5. learner.recommendations topic

    Carries the next adaptive drill — difficulty, next_scenario_prompt, estimated_duration_min — keyed by the same technician id so ordering survives.

    difficulty · next_scenario_prompt
  6. Recommender → new Waterr meeting

    recommender.js consumes the recommendation, spins a fresh scenario via Waterr's /scenarios/create-with-gpt, and pushes the join URL back to the kiosk over Server-Sent Events — the headset reads it aloud.

    SSE · /scenarios/create-with-gpt
In parallel
Tableflow → Iceberg, both topics, one click

learning.events and learner.recommendations are materialised as Apache Iceberg tables with zero extra code. Every drill outcome and every AI-authored follow-up becomes a queryable, time-travelled audit row. The IATF 16949 / ISO 9001 audit trail for plant quality + supervisors — for free.

Confluent Cloud surface area we actually touch

Apache Kafka Two topics, learner.id as partition key, 7-day retention. The system's spine.
Schema Registry (Avro) Versioned contracts for LearningEvent + LessonRecommendation — safe schema evolution across plants.
Flink SQL Watermarked source table + stateful enrichment + ML_PREDICT in a single declarative job (flink/job.sql).
AI Model Inference Anthropic Claude registered as next_lesson_model inside Confluent — invoked directly from Flink SQL.
Tableflow (Iceberg) One-click materialisation of both topics into Iceberg — audit-ready for plant quality + ISO / IATF reviewers.
Kafka Connect Datagen source primes the dashboard for warm-up demos; HTTP sink fans drill links out to the kiosk SSE channel.
